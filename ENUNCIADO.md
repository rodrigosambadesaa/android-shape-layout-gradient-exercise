# Enunciado original — Shape drawable como fondo

Ejercicio histórico de **Shapes Drawables** en Android.

Crear un recurso `shape` XML con gradiente y utilizarlo como fondo de un layout, de forma que el aspecto visual se resuelva mediante recursos XML de Android y no mediante dibujo manual en código.

La reconstrucción moderna mantiene precisamente ese requisito, ya que el objetivo del ejercicio es practicar drawables XML.

No existe una base de datos asociada.
